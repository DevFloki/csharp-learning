# csharp-learning
A collection of small console programs created while learning C# and .NET.

## Purpose
The purpose of this repo is for me to have a place to challenge myself by creating unguided projects.

I will continue making new programs and refactoring or updating older ones as i learn C# and .NET fundamentals.

## Current Programs
### Temperature Converter
A simple programs that converts temperatures between Celsius and Fahrenheit.

### To-Do List
Lets you manage a basic to-do list that allows the user to display, add, and remove tasks.

### The Library
A library management program for displaying and managing books, changing their availability, and lending them to library members.

## Requirements
.NET 10 SDK

## How to Run
Clone the repository:
```bash
git clone https://github.com/DevFloki/csharp-learning.git
```

Navigate to the project directory:
```bash
cd csharp-learning
```

Run the console application:
```bash
dotnet run
```

`Program.cs` contains the main menu used to select one of the programs.
